# Dutch Parliamentary Behaviour Dataset (Questions, legacy ParlGov version)

Written questions from Members of the Dutch lower house, asked 4-5
January 2010, with cabinet, election and party information from ParlGov,
as in earlier releases of the dataset. There are no `cabinetPeriods` or
`questionCabinet` tables.

## Usage

``` r
data(examplequestions_legacy)
```

## Format

A questionList object

## See also

[`examplequestions`](https://louwerse.github.io/dutchparl/reference/examplequestions.md)
