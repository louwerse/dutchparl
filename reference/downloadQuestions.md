# Download Dutch Parliamentary Behaviour Questions Dataset from the internet

Download Dutch Parliamentary Behaviour Questions Dataset from the
internet

## Usage

``` r
downloadQuestions(url = NULL, destfile = "questions.rds")
```

## Arguments

- url:

  URL to download from. Defaults to downloading from dutchparl
  dataverse.

- destfile:

  Destination file (rds).

## Value

Nothing. Side effect is to download the file.

## Examples

``` r
if (FALSE) { # \dontrun{
downloadQuestions()
} # }
```
